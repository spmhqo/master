Structured Problem Statement & Cause Investigation Framework

Guide / নির্দেশিকা
ব্যবহারের পরামর্শ: Problem: What specific problem does the person experience? Activity: Within which activity does the problem occur? Persona: Who experiences the problem? Purpose: What is the person trying to accomplish through the activity? Four components and their descriptions Component What to define Problem Name and description of the specific problem. Activity Name and description of the activity in which the problem occurs. Persona Name and description of the targeted audience experiencing the problem. Purpose Name and description of the intended outcome of the activity. Example Component Example Problem Difficulty identifying important concepts in lengthy textbook chapters. Activity Studying textbook chapters. Persona Class 10 students. Purpose Understanding and preparing a chapter for examinations. Resulting keyword: Difficulty identifying important concepts in lengthy textbook chapters while studying for examinations among Class 10 students.
